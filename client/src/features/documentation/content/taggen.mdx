Taggen heißt Kollegen in Aufgaben Chats mit `@` erwähnen.

## Wie funktioniert die Taggen funktion?

1. Im Chat der Aufgabe schreibst du `@`
2. Du wählst die Person aus der Liste
3. Die Person bekommt einen Hinweis dass sie erwähnt wurde
4. Über den Hinweis kann sie die Aufgabe öffnen

## Warum?

Damit Zuständige schnell sehen wenn sie in einer Aufgabe gebraucht werden ohne die ganze Liste durchzusuchen.
