# Font deployment assets

Supply full, licensed TTF files here or set DOCUMENT_FONT_DIR to another directory.
Licensed fonts are intentionally ignored by Git. See docs/styled-documents.md for filenames
and installation instructions. Do not extract or redistribute PDF font subsets.

Carlito (SIL Open Font License, see Carlito-OFL.txt) is committed as the stand-in
for Calibri, and for Arial, Helvetica, and Times New Roman when those licensed
files are missing. Calibri line breaks match because Carlito uses the same advance
widths. Arial and Times keep the requested family name in the editor, with Carlito
glyphs until the licensed files are installed.
