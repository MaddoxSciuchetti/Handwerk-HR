## Was ist die Gruppenrechte Funktion?

Beim Microsoft Konto anlegen kannst du optional Entra Gruppen auswählen. Darüber bekommt der Nutzer Rechte in SharePoint und Teams.

## Wie funktioniert die Gruppenrechte Funktion?

1. Du startest die Automatisierung Microsoft Konto anlegen
2. Du wählst optional eine oder mehrere Entra Gruppen aus
3. Mit Gruppen: das Konto wird angelegt und den Gruppen hinzugefügt — die Rechte (SharePoint / Teams) hängen an den Gruppen in Microsoft
4. Ohne Gruppen: es entsteht nur das Konto mit Lizenz

## Warum?

Rechte sollen nicht nachträglich von Hand in Microsoft gesetzt werden. Beim Anlegen des Kontos ist klar welche Gruppen der Nutzer braucht.
