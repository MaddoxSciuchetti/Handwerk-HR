## Was ist die Automatisierung?

Automatisierungen sind fertige Abläufe für Microsoft oder Crewmeister die du an Aufgaben bzw. Templates hängst. Beim Start führt Hadox den Ablauf aus.

## Wie funktioniert die Automatisierung?

1. Du öffnest die Aufgabe oder das Template
2. Du wählst die Automatisierung z.B. Microsoft Konto anlegen
3. Du startest die Automatisierung
4. Hadox führt den Ablauf in Microsoft oder Crewmeister aus

Welche Automatisierungen unterstützt Hadox aktuell?

- [Microsoft](/docs/automatisierungen/microsoft)
- [Crewmeister](/docs/automatisierungen/crewmeister)

Extra Funktionen:

- [Geplante Deaktivierung](/docs/extra-funktionen/geplante-deaktivierung)
- [Admin ping Funktion](/docs/extra-funktionen/admin-pingen)
- [Gruppenrechte zuweisen](/docs/extra-funktionen/gruppenrechte)

## Warum?

Wiederkehrende Onboarding / Offboarding Schritte sollen nicht jedes Mal von Hand in Microsoft oder Crewmeister gemacht werden.
