## Was ist die Crewmeister Automatisierung?

Über die Crewmeister Automatisierung lässt Hadox Aktionen in Crewmeister ausführen. Dazu gehört:

1. Konto anlegen
2. Konto deaktivieren
3. Mitgliedschaft entfernen

## Wie funktioniert die Crewmeister Automatisierung?

1. Du hängst die gewünschte Crewmeister Automatisierung an die Aufgabe oder das Template
2. Du startest die Automatisierung
3. **Konto anlegen:** Für den Nutzer wird in Crewmeister eine Mitgliedschaft angelegt. Dafür braucht es die private E-Mail Adresse. Hadox schickt die Einladung über Crewmeister; Crewmeister sendet die Einladungs Mail selbst (kein Passwort von Hadox wie bei Microsoft)
4. **Konto deaktivieren:** Die Mitgliedschaft wird deaktiviert. Optional kannst du ein Datum setzen — siehe [Geplante Deaktivierung](/docs/extra-funktionen/geplante-deaktivierung)
5. **Mitgliedschaft entfernen:** Entfernt die deaktivierte Crewmeister Mitgliedschaft dauerhaft, auch bei einer noch offenen Einladung. Der globale Crewmeister Login bleibt bestehen

<Hint>
Mitgliedschaft entfernen nur ausführen wenn diese Mitgliedschaft wirklich weg soll.
</Hint>

## Warum?

Zeiterfassung und Crewmeister Zugänge sollen beim Onboarding / Offboarding mitlaufen statt separat in Crewmeister gepflegt zu werden.
