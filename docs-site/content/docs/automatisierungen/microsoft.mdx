## Was ist die Microsoft Automatisierung?

Über die Microsoft Automatisierung lässt Hadox Aktionen in Microsoft 365 ausführen:

1. Konto anlegen
2. Gruppenrechte zuweisen
3. Teams Nachrichten schicken
4. Emails schicken
5. Konto deaktivieren

## Wie funktioniert die Microsoft Automatisierung?

1. Du hängst die gewünschte Microsoft Automatisierung an die Aufgabe oder das Template
2. Du startest die Automatisierung
3. **Konto anlegen:** In Microsoft 365 wird ein Konto angelegt. Die Arbeits-E-Mail kommt aus Vorname, Nachname und der konfigurierten Domain. Ein Passwort wird erstellt und an die private E-Mail Adresse geschickt
4. **Gruppenrechte zuweisen:** Optional beim Anlegen — siehe [Gruppenrechte zuweisen](/docs/extra-funktionen/gruppenrechte)
5. **Teams / Email / Deaktivieren:** Der gewählte Ablauf läuft über die Automatisierung an der Aufgabe
6. Bei Deaktivierungen kannst du optional ein Datum setzen — siehe [Geplante Deaktivierung](/docs/extra-funktionen/geplante-deaktivierung)

<Hint>
Microsoft bietet keine Schnittstelle an um eine Lizenz zu kaufen. Um ein Nutzer durch die Automatisierung anzulegen muss es min. 1 freie Lizenz geben. Ist diese Lizenz nicht vorhanden schlägt die Konto Erstellung fehl.

Wenn keine Lizenz mehr frei ist kannst du die Administration [anpingen](/docs/extra-funktionen/admin-pingen).
</Hint>

## Warum?

Ohne Microsoft Automatisierung müsstest du Konten, Gruppen, Teams Nachrichten und Deaktivierungen von Hand in Microsoft 365 machen. Hadox hängt das an eure Onboarding / Offboarding Aufgaben.
