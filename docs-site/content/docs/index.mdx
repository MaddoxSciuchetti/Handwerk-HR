## Was ist Hadox?

Hadox ist eine minimalistische software die einem Betrieb beim onboarden und offboarden von Mitarbeitern hilft.

## Was kann Hadox?

Was Hadox kann lässt sich in zwei Kategorieren aufteilen

1. Hadox API

Mit der Hadox API (Application Programming Interface) kann Hadox mit anderen Diensten z.B Microsoft kommunizieren und somit Aufgaben automatisieren

2. Hadox Prozessoptimierung

Hadox Prozessoptimierung beinhaltet Funktionen wie z.B das Automatische ausfüllen von Verträgen mit Daten aus dem Fragebogen. Anders als die API braucht die Prozessoptimierung keine Verbindung zu externen Diensten — alles läuft in Hadox.

## Warum?

Ziel ist es möglichst viele Aufgaben zu automatisieren sodass mehr Arbeitszeit für wichtigere Aufgaben geschafft werden kann
