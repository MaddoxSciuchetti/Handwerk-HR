# Project Overview

This repository is a web application that solves the problem of tedious onboarding and offboarding work in high job fluctuation industries, starting with HVAC. It solves this problem by 1. Letting Companies connect various services with this application so that all talk to one another 2. Implementing a opinionated way on how a onboarding and offboarding should happen, cutting out many previous steps that proved to be unnecessary.
